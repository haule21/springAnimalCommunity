Phase 0: 민감 정보 분리 작업 완료

작업 일시: 2024년
작업자: AGI

=== 작업 내용 ===

1. .gitignore 파일 업데이트
   - application-local.properties 추가
   - application-local.yml 추가
   - *.jks, *.p12, *.key 파일 제외
   - messageAPI.java 제외

2. 민감 정보 분리
   - application.yml에서 DB 접속 정보 제거 (username, password, jdbc-url)
   - application.yml에서 SSL 설정 정보 제거 (key-store, key-store-password, key-alias)
   - RootConfig.java에서 하드코딩된 DB 정보 제거
   - Spring Boot의 자동 설정을 사용하도록 변경

3. application-local.properties 생성
   - DB 접속 정보 (jdbc-url, username, password)
   - SSL 설정 정보 (key-store, key-store-password, key-alias)
   - SMS API 키 정보 (sms.api.key, sms.api.secret, sms.api.url)
   - application-local.properties.example 템플릿 파일 생성

4. messageAPI.java 리팩토링
   - 하드코딩된 API 키 제거
   - @Component로 Spring Bean 등록
   - @Value를 통한 설정 파일 주입
   - 싱글톤 패턴 제거 (Spring의 의존성 주입 사용)

5. MainController.java 수정
   - messageAPI.getInstance() 제거
   - @Autowired를 통한 의존성 주입으로 변경

=== 변경된 파일 ===
- raelfarm/.gitignore
- raelfarm/src/main/resources/application.yml
- raelfarm/src/main/resources/application-local.properties (신규)
- raelfarm/src/main/resources/application-local.properties.example (신규)
- raelfarm/src/main/java/haule/raelfarm/config/RootConfig.java
- raelfarm/src/main/java/haule/raelfarm/singleton/messageAPI.java
- raelfarm/src/main/java/haule/raelfarm/controller/MainController.java

=== 보안 개선 사항 ===
- 모든 민감 정보가 Git에 커밋되지 않도록 처리
- 로컬 개발 환경 설정 파일 분리
- 설정 파일 템플릿 제공으로 다른 개발자도 쉽게 설정 가능
