# 동물 커뮤니티 사이트
- 현재 운영되고 있지 않아요. :disappointed_relieved:
  
## Version 
- Spring Boot 3.0.1
- Java 18
- (내부)Apache-tomcat 10.0.27
- Gradle
- Mysql 8
- html (thymeleaf), css, javascript 

## 기능
- 회원가입 및 로그인을 구현했어요.
- 전화번호 인증으로 안전하게 회원가입할 수 있어요.
- 로그인한 사용자는 게시판을 작성할 수 있어요.
- 게시판에 이미지를 업로딩 할 수 있어요.
- 내가 올린 게시판 조회 수를 확인할 수 있어요.
- 좋아하는 게시판을 추천할 수 있어요.
- 보고싶은 게시판을 검색할 수 있어요.
- 댓글을 작성할 수 있어요.
- 댓글에 댓글을 작성할 수 있어요.
- 좋아하는 댓글을 추천할 수 있어요.
